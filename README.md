**Authors:** Junwei L., Juan, Abril, Marina

## Project Overview

This project investigates Hereditary Lysozyme Amyloidosis (HLA), focusing on the relationship between changes in the lysozyme gene and protein sequence, protein structure, and biological function.

The project addresses the following questions:

- How can changes in gene and protein sequences and protein structure explain the molecular basis of the disease?
- What can gene and protein comparisons reveal about the affected biological function?
